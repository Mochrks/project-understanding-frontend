## Overview

**Fullstack Mastery Hub** is an integrated learning platform designed with a **Nike Editorial Aesthetic**. This project covers end-to-end development, from highly responsive user interfaces to scalable backend architectures powered by **Spring Boot**.

The primary focus of this project is a deep understanding of system architecture, data security, and high performance, following the philosophy: *"Move Fast. Build Strong."*

## Features

- **Nike-Inspired UI**: Minimalist design, bold typography (Bebas Neue), and a premium monochromatic color scheme.
- **Frontend Mastery**: Modern React implementation with TypeScript and utility-first Tailwind CSS.
- **Backend Excellence**: Solid Spring Boot architecture with efficient database management and RESTful principles.
- **Mastery Tracks**: Structured learning paths for Frontend, Backend, and Infrastructure.
- **Docker Ready**: Full containerization for consistent deployment across environments.

## Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Framer Motion, Lucide Icons.
- **Backend**: Spring Boot 3.x, Java/Kotlin, Spring Security, JPA/Hibernate.
- **Database**: PostgreSQL / MySQL.
- **DevOps**: Docker, GitHub Actions CI/CD.

## Setup & Installation

- **Clone the repository**
    ```bash
    git clone https://github.com/Mochrks/web-understanding-fullstack.git
    cd web-understanding-fullstack
    ```

- **Frontend Setup**
    ```bash
    npm install
    npm run dev
    ```
